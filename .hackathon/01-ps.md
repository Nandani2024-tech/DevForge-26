## 1. Problem definition
- L1 Users: the hospital research-database team in Yugaantar Pradesh. Judged by the organisers' automated evaluator and attacker.
- L2 Pain: patient records are messy: 4 hospitals, EN/हिंदी/Hinglish, CSV/TSV/JSON/FHIR/notes, many encodings. PII is also in file names, keys, headers, metadata and base64.
- L3 Action: an offline, CPU-only, LLM-free firewall. It removes all PII, keeps medical values exact, gives one keyed pseudonym per real patient, and quarantines what it can't clean.
- L4 Metric: the official score out of 100 on 3 hidden datasets. Proxy: check_dev.py targets (sec 6) plus CONTRACT OK plus READY TO SUBMIT.
- L5 Hook: cross-script identity matching, plus per-patient keyed shifts and generalisation that beat a voter-list attacker, plus context rules that keep working on unseen formats.

## 3. Core user flow
1. Evaluator runs `setup` (pip, network on, .venv), then `run` with RAKSHA_SECRET, read-only {input}, empty {output}, no network.
2. Walk input in sorted order, decode, then parse or quarantine.
3. Pass 1: extract identity evidence per record and cluster it into patients (HMAC IDs). Pass 2: detect and replace PII, shift dates per patient, generalise QIs, suppress rare cells, write the pseudonym inside the record.
4. Write sanitized/, records.jsonl, report.json; exit 0. Evaluator scores and attacks, then reruns with the same and with another secret.

## 7. Edge cases and failure modes
- Empty, truncated/invalid JSON, undecodable, pdf/jpg/xml -> quarantine with a reason, never sanitized/. 1,500-deep JSON -> iterative parse or quarantine, never a RecursionError crash.
- JSON behind .csv -> detect by content. Duplicate files with the same SHA -> each listed and processed.
- Huge bulk export -> streaming / linear time; scaling exponent <= 1.15.
- A filename with PII -> rename deterministically and map it in report. An error message must never echo content.
- Missing RAKSHA_SECRET -> non-zero exit, never a silent default (assumed). No network -> gazetteers vendored, no downloads. Concurrency: N/A (one batch run).

## 11. Traps
- Tuning to dev names, headers or files: the chaos dataset costs the reference ~30 points. Use context and column semantics, not lists.
- Over-redaction: kills utility, which kills privacy credit (< 0.40 coupling) and F2 precision (doctors, doses, clean/ files).
- A global or unkeyed date shift or pseudonym: A5 recovers a global shift, A6 inverts hashes, A7 links releases. Use per-patient HMAC keyed by the secret.
- Transitive / name-only clustering merges homonyms. A false merge costs more than null.
- Pseudonym only in records.jsonl, not inside the record: 0 consistency credit and no A4 effect.
- Leaks via logs, exceptions, temp files or filenames; nondeterminism from set/dict/time order; Windows-only paths or RSS code that breaks on Linux.
